# 陪伴组件

五个模板共享一级能力，但使用不同的预制表达：

```text
Window      Frosted Glass Panel
Vinyl       Deck Controls
Instrument  Control Surface
Route       Wayfinder
Symbols     Symbol Tokens
```

## 一级能力

- 重新开始入静引导；
- 天气强度：关闭 / 低 / 中；
- 声音：播放 / 暂停 / 音量；
- 四阶段切换；
- 阅读累计计时；
- 25 分钟番茄钟。

## 计时与番茄钟

- 普通计时支持暂停、继续、重置；
- 番茄钟支持开始、暂停、继续、重置；
- 番茄钟结束后给出克制的视觉或声音反馈；
- 不生成图表、任务列表或复杂生产力 UI；
- 页面刷新后计时可以重置。

## 设计约束

- 默认安静，不遮挡首屏主体；
- 任何一级能力最多两步可达；
- 标签清晰，不能只靠难懂图标；
- 触摸区域至少 44px；
- 有可见焦点状态；
- 支持键盘与触屏；
- 模板主体和书籍个性优先于通用面板外观。
