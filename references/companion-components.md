# 陪伴组件

五个模板共享一级能力，但使用不同的预制表达：

```text
Window      Frosted Glass Panel
Vinyl       Deck Controls
Instrument  Control Surface
Route       Wayfinder
Symbols     Symbol Tokens
```

## 一级能力

- 重新开始入静引导；
- 天气强度：关闭 / 低 / 中；
- 声音：播放 / 暂停 / 音量；
- 3–6 个目录阶段切换；
- 阅读累计计时；
- 25 分钟番茄钟。

## 计时与番茄钟

- 普通计时支持暂停、继续、重置；
- 番茄钟支持开始、暂停、继续、重置；
- 番茄钟结束后给出克制的视觉或声音反馈；
- 不生成图表、任务列表或复杂生产力 UI；
- 页面刷新后计时可以重置。

## 设计约束

- 共享运行时样式只是质量底线，不是最终视觉；必须用书籍专属 CSS 继续主题化字体、材质、形状和布局；
- 禁止退化为一排相同胶囊按钮、默认表单控件或无层次的透明面板；
- 默认安静，不遮挡首屏主体；
- 阶段标题、目录范围和 `readingHint` 统一在预制组件中展示，书籍专属代码不得重复创建阶段卡、说明面板或另一套控制面板；
- 禁止持续漂浮的文字胶囊、标签群、随机游走文字；场景文字如有必要，每次最多一句且短暂显现后自动退场；
- 任何一级能力最多两步可达；
- 标签清晰，不能只靠难懂图标；
- 触摸区域至少 44px；
- 有可见焦点状态；
- 支持键盘与触屏；
- 模板主体和书籍个性优先于通用面板外观。
