# 入静引导

每次页面加载或刷新都显示入静首页。
入静引导是 15–25 秒的有声阅读前奏，不是欢迎页或功能教程。

## 共享节奏

```text
settle   让身体和视线慢下来
orient   自然呈现读前坐标
attune   让声音、天气和画面对齐
begin    进入阅读陪伴
```

## 声音启动

浏览器通常禁止零操作有声自动播放。
首页必须提供一个清晰、诗性、符合书籍气质的开始动作。

用户点击后：

1. 立即尝试播放 `./assets/audio/bgm.mp3`；
2. BGM 不可用时立即播放环境音；
3. 声音缓慢淡入；
4. 同时启动入静文字和画面变化。

引导期间不得无声。不得等待远程生成或本地 JSON 请求后才决定声音。

## 文本

- 简短、诗性、面向未读者；
- 不剧透；
- 不使用未解释专有名词；
- 不逐项讲解功能；
- `orient` 自然包含 `world / concern / notice / permission`；
- `begin` 用一句具有书籍气质的短句邀请读者开始。

## 模板表现

- Window：光线、天气和窗外世界逐渐显现；
- Vinyl：设备通电、唱片旋转、唱针落下；
- Instrument：噪声降低，核心信号稳定；
- Route：远方与路径逐渐显现；
- Symbols：象征物从雾、影或光中显形。

## 约束

- 必须有跳过；
- 刷新后重新出现；
- 不保存已完成状态；
- 不使用机械倒计时；
- 引导结束后遮罩彻底退出；
- `prefers-reduced-motion` 下仅保留淡入淡出；
- 用户跳过后仍必须进入有声陪伴空间。
