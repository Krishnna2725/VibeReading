# 唱机与黑胶

## 模板标识

当书籍涉及音乐史、爵士时代、复古文化、回忆录、散文，或者强调“声音、节奏、循环的时间”时，使用 `vinyl` 模板。

## 概念图作用

`concept-image.png` 直接作为**专辑封套 (Album Cover)**。通常需要被裁切或呈现为一个 1:1 的正方形黑胶封套比例。

为前端生成该图像时：它需要具备纯粹的平面设计感，可以带有黑胶唱片包装封套的磨损划痕（前端可通过 CSS 叠加），或者是复古厂牌的贴纸样式。书名和作者应如同专辑名和厂牌一般进行排版。

## 美术指导偏好

复古音乐设备、专辑包装设计、黑胶质感、工业金属与实木、精密刻度、温暖的功放管背光、旧纸张印刷物。

## 世界动词

上盘播放 (drop needle) / 调节 (tune) / 翻阅内页 (read liner notes)

## 推进机制

通过控制唱机的物理播放状态（开/关、转速、唱臂位置）来驱动情绪和阅读内容的切换。

优秀的节奏示例：
```text
观赏封套 -> 抽出带有书名标签的唱片 -> 放下唱臂伴随炒豆声 -> 翻阅放置在唱机旁的印刷内页（书籍正文）
```

## 协议映射

- `entry`: 专辑封套 (Album Cover)，巨大的 1:1 正方形展示。
- `exploration`: 唱机控制台 (Turntable Deck)，屏幕主体变为唱盘、唱臂、拨动开关和音量表。唱片转动是核心视觉。
- `companion`: 唱片内页摘录 (Liner Notes / Inner Sleeve)。无需等待解锁，作为物理物件放在唱机旁或背景中，随时可以抽出阅读书籍的长文本内容。

## 交互物件与书籍隐喻

维持极致的复古拟物感，并将书籍元素无缝融入硬件与包装中：
- **黑胶唱片标签 (Vinyl Label)**：唱片中心的圆标，上面印有书名、章节号，如同 A面/B面 (Side A / Side B)。
- **金属铭牌 (Metal Plate)**：唱机木质底座上镶嵌的一块铜牌，上面刻着书籍的核心引言或题记。
- **物理开关与旋钮**：用于切换环境底噪（如雨声、篝火声）或控制阅读节奏。
- **唱片内页 (Liner Notes)**：**作为书籍正文的载体**。它可以表现为一张折叠的复古印刷歌词单或小册子，随意地搁在唱机旁边。点击即可拉近放大，进行沉浸式阅读。排版必须严格遵循旧式印刷品的网格、衬线字体和纸张泛黄质感。

## 模板运行契约

- 拓扑：`cyclical` 或 `sequence`；封套、面别、落针和播放状态形成一个完整仪式。
- 默认渲染：`dom` / `three-diegetic`；不需要空间操作时优先 CSS 拟物。
- 适配天气：浮尘、热浪、窗外雨影、薄雾、缓慢风；天气应落在设备与房间材质上。
- 推荐阅读工具：`ambience-control`、`timer`、`notes`、`stage-navigation` 中选择 2-4 项。
- Companion 变形：唱片内页随时可抽出阅读，机器继续作为低干扰时间背景。

## 前端实现模式

本节提供该模板的“高质量前端实现语法”指引，用于指导 Coding Agent 产出具备物理感、空间感和极佳交互反馈的 Web 原型。

### 1. 结构与 DOM 层级
这必须是一套极致拟物的硬件系统 (Skeuomorphism)：
- **`z-index: 1` Turntable Deck (唱机甲板)**: 背景基座。使用实木纹理或深色拉丝金属面板。
- **`z-index: 2` The Vinyl (黑胶唱片)**: 圆形的唱片主体。放置在甲板中央。
- **`z-index: 3` Hardware Knobs & Switches (物理控件)**: 各类开关、旋钮，必须具有独立的高光和投在甲板上的阴影。
- **`z-index: 4` The Tonearm (唱臂系统)**: 必须悬浮在唱片和甲板上方，具有长长的阴影以体现高度差。
- **`z-index: 5` Liner Notes (唱片内页/阅读区)**: 随时可以从侧边抽出或在点击旁边的册子时滑出的物理纸张，用于承载大段的书籍文字。

### 2. 交互与动效技法
- **黑胶纹理与高光**: 绝不仅是用一张黑圆图！必须用 CSS 绘制凹槽反光：
  ```css
  background: repeating-radial-gradient(#111 0, #111 2px, #0a0a0a 2px, #0a0a0a 4px),
              conic-gradient(rgba(255,255,255,0.05) 0deg, transparent 30deg ...);
  background-blend-mode: screen;
  ```
- **唱臂的物理运动**: 必须利用精确的 `transform-origin` 设在唱臂尾部支点，按下播放时使用平滑的贝塞尔曲线 `transform: rotate()` 让唱针缓缓降落到盘面上。
- **转动与底噪 (Vinyl Crackle)**: 唱片播放时必须有 `animation: spin 1.8s linear infinite;`。如果没有背景音轨，务必使用极简的 Web Audio 或 HTML5 Audio 垫上一层轻微的黑胶炒豆声（白噪音），这对氛围至关重要。

### 3. 可选的 Three.js 三维唱机

`vinyl` 高度适合 `three-diegetic`：抽出唱片、放盘、拨动唱臂和翻转封套都具有明确的阅读隐喻。Three.js 应增强机械动作的重量，而不是复刻现代音乐播放器。

- 推荐世界动作：从封套抽出唱片、将唱片放上转盘、移动唱臂落针、翻转唱片或封套。
- 唱臂位置、转速和面别必须同步驱动声音、灯光、阅读阶段与 Liner Notes 内容。
- 唱片内页、书籍正文、章节标签和控制语义继续使用 DOM；不要把长文本烘焙进 3D 纹理。
- 为落针、暂停、换面和打开内页提供 DOM 等价控件；移动端可简化唱臂拖拽为可访问的落针动作。
- 若页面只需要唱片旋转和唱臂摆动，CSS 已足够时优先使用 DOM/CSS。
- 禁止加入无关的自由镜头、复杂房间漫游或只展示模型而不推进阅读的唱机动画。

### 4. 各模式实现规范
- **Entry & Exploration**:
  - Entry 是抽丝剥茧的仪式：从纸质封套 (`concept-image`) 中抽出黑胶。
  - Exploration 必须给人“我在操作精密机械”的厚重感，按键要有清脆有力的物理下沉反馈。
- **Companion Mode (阅读陪伴模式)**:
  - 陪伴模式随时可用。
  - **绝不**直接在转动的黑胶上或玻璃遮罩上叠字。
  - 文字必须落在真实的物理载体上：如一张展开的复古纸张（Liner Notes）。利用多重 `box-shadow` 和轻微的 `rotate` 让它看起来像是刚从封套里抽出来搁在桌上的实体物件。

### 5. 绝对禁忌
- ❌ **现代流媒体播放器 UI**：绝对禁止把它做成带底部细长进度条和现代扁平图标的播放器界面！必须维持纯粹的复古拟物感。
- ❌ **扁平化的设计**：在这个模板里，纯粹的 Flat Design 是非法的。旋钮没有高光、唱臂没有阴影是不可接受的。
- ❌ **书籍元素剥离**：不要只做了一个能播放的唱机。必须让机器和物件成为书籍的隐喻（例如中心的圆标印着书名，铭牌刻着题记，内页承载着正文）。
