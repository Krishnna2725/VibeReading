# Window

## Role

用一处可持续凝视的窗边空间，让读者通过风景、天气、光线和短文字进入书籍。

## Best For

文学小说、自然、地方、季节、孤独、城市观察、等待、回忆。

## Avoid

主要依赖系统参数、机械对象、旅途路线或强象征物才能成立的书。

## Primary Production Mode

图像主导。

生图直接生成完整窗边阅读空间。前端不重画复杂窗框、窗台和拟物装饰，只负责天气、文字、入静引导、阶段切换和陪伴组件。

## Creative Budget

- 一张完整母图；
- 最多三张基于母图的图生图变化；
- 四阶段的天气、光线、文字与声音；
- 不遮挡主体的毛玻璃陪伴组件。

## Visual Preset

母图为 16:9，包含完整窗户结构、室内边缘、窗外风景和 UI 安全留白。

图生图只改变：

```text
窗外风景、天气、季节、时间、光线
```

必须保持室内结构、观察视角、主体和书籍视觉身份连续。

## BGM Preset

全书一首纯音乐 BGM。四阶段通过环境音、天气和光线表达变化。

## Weather Preset

雾、风、雨、雪、凝露、光尘或缓慢阴影。
天气是画面的呼吸，不是廉价粒子层。

## Companion Preset

`Frosted Glass Panel`

面板贴近右侧或右下角，面积小，不遮挡主体。包含入静、天气、声音、四阶段、计时和番茄钟。

## Entry Guide Behavior

点击开始后声音淡入，窗外光线和天气逐渐显现，读前坐标以简短文字进入视野。

## Stage Expression

四阶段使用最多四张连续窗景。若只生成一张或部分变化图，剩余阶段通过天气、光线、环境声、文字和局部 UI 表达。

## Forbidden

- 前端重新绘制复杂窗框、窗台或大型装饰 SVG；
- 擦玻璃、拉窗帘等必须完成的复杂交互；
- 静态壁纸上堆满控件；
- 毛玻璃面板遮挡主体；
- 四张图像像四个不同空间。

## Acceptance

- 首屏首先读作一处真实窗边阅读空间；
- 四阶段切换平滑，空间连续；
- 画面始终是主角；
- 入静结束后面板安静退居边缘。
