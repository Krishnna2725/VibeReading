# 图片生成

## 通用规则

- 默认 16:9；
- 画面主体完整；
- 明确 UI 安全留白；
- 不包含可读文字、Logo、导航、面板或生成式 UI；
- 图片必须贴合书籍身份与选中模板；
- 不生成廉价奇幻、游戏界面、SaaS 背景或通用壁纸。

Prompt 应明确：

```text
书籍核心气质
模板图像角色
主导精神画面
构图和安全留白
光线、材质、天气
16:9 裁切要求
禁止项
```

## Window：母图加图生图

先生成一张完整窗边阅读空间母图。
母图必须直接包含窗户结构、室内边缘、窗外风景、光线和可用留白。

确认母图后，最多进行三次图生图：

- 保持室内结构、窗户、视角、主体和视觉身份；
- 只改变窗外风景、天气、季节、时间和光线；
- 四张图切换时不能像不同房间或不同网站；
- 前端不得重新绘制复杂窗框和窗台。

## 其他模板

- Vinyl：生成一张书籍专属专辑封套 / label 图；
- Instrument：生成一张背景环境、仪器表面或屏幕纹理；
- Route：生成一张具有清晰方向和安全留白的旅途空间；
- Symbols：生成一张宁静的象征空间或仪式表面。

其他模板默认只生成一张主要图像，四阶段变化由前端氛围表达完成。
