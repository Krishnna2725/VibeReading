# VibeReading Skill

VibeReading 是一个面向 AI Agent 的阅读体验生成 Skill。它会把一本书转译成一个可进入的沉浸式网页空间：有视觉概念、环境氛围、空间交互、阅读阶段、环境音和低干扰陪伴模式。

它不是电子书阅读器，也不是书籍介绍页。

它的目标是生成：

- 一个阅读陪伴空间
- 一段可进入的氛围
- 一个与书籍气质绑定的互动情绪场
- 一种阅读前和阅读中的数字仪式

用户应该感觉自己正在进入一本书的世界，而不是浏览一个网页。

## 设计哲学

大多数 AI 生成的“漂亮网页”失败的原因很相似：它们开始写代码太早。

如果没有清晰的艺术方向，模型很容易退回熟悉的网页套路：hero section、卡片、玻璃拟态、通用动画、随机氛围特效、无限滚动布局。结果可能在技术上能运行，但情感上是空的。

VibeReading 采用另一种方式。

它不把网页当作内容容器，而是把网页当作由一本书的情绪核心、象征系统和空间隐喻生成的数字艺术空间。

因此，工作流不会直接从“写一个页面”开始，而是先建立艺术方向，再进入实现。

## 为什么拆成多阶段工作流

视觉一致性很难在一次生成里完成。模型如果直接进入前端代码，很容易出现：

- 通用布局
- 重复的交互结构
- 流行但无意义的视觉风格
- 与文本气质脱节的动画
- 不匹配书籍情绪的 UI 组件
- 混杂的“AI 审美汤”

为了避免这些问题，VibeReading 将艺术方向和工程实现拆开：

```text
Book
→ Art Direction
→ Concept Image
→ Design Language Extraction
→ Interaction Structure
→ Frontend Generation
```

这更接近电影、游戏、装置艺术和产品设计中的真实创作流程。

概念图在这里不是装饰，而是艺术锚点。它在代码生成前先稳定页面的光线、材质、空间节奏、象征物件、字体气质和交互语言。只有当视觉身份稳定后，系统才进入交互前端生成。

这样会显著提升：

- 审美一致性
- 交互原创性
- 情绪具体性
- 动效连贯性
- 氛围质量
- 页面整体的“在场感”

这个项目与其说是在生成网站，不如说是在生成沉浸式阅读空间。

## 核心交互理念

VibeReading 拒绝把阅读界面做成效率工具。

生成的体验应该是：

- 非线性的
- 探索驱动的
- 氛围先行的
- 以物件和空间为交互入口的
- 带有仪式感的
- 最终服务于阅读陪伴的

用户不应该觉得自己在操作软件，而应该觉得自己正在：

- 进入
- 揭示
- 激活
- 发现
- 调频
- 栖入

交互被视为环境叙事，而不是 UI 导航。

每个页面最终都会进入一个更安静的 Companion Mode：一个低干扰的氛围空间，可以在用户阅读真实书籍时留在旁边。

## 为什么这更适合 AI

大语言模型很擅长：

- 象征解释
- 情绪综合
- 艺术指导语言
- 概念空间构建
- 氛围生成

但它们不擅长在同一轮生成里同时维护高级艺术方向和前端实现细节。

VibeReading 的工作流先给模型一个稳定的艺术北极星，再让它写代码。因此生成结果通常更少模板感、更不像普通 AI 网页，更容易拥有具体的情绪、独特的交互和可记住的视觉。

## 功能特性

- **多阶段自主工作流**：从书籍背景检索、模板选择、艺术方向、概念图、视觉简报、空间规格到前端生成。
- **8 个交互模板**：窗景、档案、神谕、仪器、排练、文字迷宫、路线、黑胶唱机。
- **概念图驱动的视觉语言**：先生成概念图，再抽取前端可实现的设计语言。
- **固定视口沉浸体验**：避免传统长网页，用空间状态和环境引擎推进体验。
- **低干扰陪伴模式**：包含计时器、阅读阶段、环境音、灯光/氛围切换、边注保存和专注模式。
- **静态输出**：生成 `index.html`、`style.css`、`app.js` 和本地资产，可直接在浏览器打开。

## 使用方式

1. 将 `vibereading-skill/` 安装或加载到支持 Skill / Workspace 指令的 AI Agent 中（推荐使用Codex及其他具备生图和多模态能力的模型平台）。
2. 确保 Agent 具备联网检索能力。强烈建议同时具备图像生成能力，因为概念图会显著影响最终页面质量。
3. 建议：如果需要自动生成 BGM，请设置环境变量 `MINIMAX_API_KEY`。如果没有设置，Skill 会跳过 BGM，并使用内置环境音。
4. 直接对 Agent 发出类似指令：

```text
给《百年孤独》生成一个阅读陪伴页面
```

生成完成后，结果会出现在：

```text
vibereading-skill/output/[本次生成目录]/
```

打开其中的 `index.html` 即可查看页面。

## 测试

```bash

```

```bash

```

## 开源与贡献

欢迎通过 Issue 或 PR 参与：

- 增加新的交互模板
- 优化已有模板的前端表现语法
- 改进视觉简报、空间规格或校验规则
- 补充测试和示例
- 改进音频、动效和无障碍体验

新增模板时，请将模板文件放入 `vibereading-skill/references/templates/`，并同步更新 `vibereading-skill/references/template-index.md` 和 `vibereading-skill/SKILL.md` 中的模板 ID 列表。
