# VibeReading

VibeReading 是一个面向 AI Coding Agent 的阅读陪伴页面生成 Skill。

它会根据一本书的目录、气质与阅读节奏，生成一个可以直接在浏览器打开的沉浸式网页空间。页面通过画面、音乐、环境音、天气、文字与低干扰交互，帮助读者在正式阅读前进入状态，并在阅读过程中保持陪伴感。

它不是电子书阅读器，也不负责讲解剧情。它更像一扇通往书中气氛的窗、一台为阅读调频的装置，或一段可以留在桌面上的数字仪式。

## 当前版本

当前稳定版本提供五种阅读空间：

- **Window**：以窗景、光线和天气变化陪伴阅读。
- **Vinyl**：以唱片机、唱片与声音仪式组织阅读体验。
- **Instrument**：把页面设计成收音机、终端或其他阅读接收器。
- **Route**：将章节进程转译为路线、站点与旅途。
- **Oracle**：通过牌组、符号与抽取动作建立阅读仪式。

Agent 会根据书籍选择合适的模板，并基于真实目录将全书划分为 3 至 6 个无剧透阅读阶段。每个页面都包含读前引导、纯音乐 BGM、天气或环境氛围、阶段切换、阅读计时和 25 分钟番茄钟。

页面面向 16:9 横屏设计，生成后可以直接双击 `index.html` 运行。

## 使用方式

1. 将本仓库作为 Skill 加载到支持 Workspace 或 Skill 指令的 AI Coding Agent 中。
2. 建议为 Agent 提供联网检索能力，以便查询书籍目录；图像生成能力可以进一步提升部分模板的效果。
3. 如需自动生成 BGM，请设置环境变量 `MINIMAX_API_KEY`。未配置时，Agent 可以使用已有音乐或环境音完成页面。
4. 向 Agent 发出类似指令：

```text
给《百年孤独》生成一个阅读陪伴页面
```

生成结果位于：

```text
output/YYYY-MM-DD-BookTitle-purpose/
```

打开生成目录中的 `index.html` 即可开始使用。

## 项目结构

```text
SKILL.md       Skill 的主流程与核心生成契约
references/    模板、视觉、引导、天气、音频和技术参考
runtime/       声音、天气、阶段与计时等共享能力
scripts/       页面脚手架、BGM 生成和代码校验工具
assets/        可复用的本地音频资源
output/        本地生成结果，默认不提交 Git
```

如果你正在使用或修改这个 Skill，请从 [`SKILL.md`](SKILL.md) 开始。Agent 应按生成步骤逐步读取所需参考文件，而不是一次加载全部文档。

自动校验只负责代码、资源路径和核心交互是否可运行；最终的艺术方向与视觉质量仍由人来判断。
